# Artifact production contracts

## Brand Anchor

Make the promise, proof, CTA, voice, tokens, image direction, prohibited claims, approver, and constraints explicit. If an input is inferred, label it `assumption` until approved.

## Landing page

- Mobile-first hierarchy: promise -> proof -> offer -> objection handling -> CTA.
- One dominant CTA; secondary actions must not compete.
- Define loading, empty, success, and error states for interactive elements.
- Test at narrow mobile, common laptop, keyboard-only, and reduced-motion settings.

## Social carousel

- Cover earns attention without clickbait.
- One claim or transition per card; card 10 closes with the same primary CTA.
- Keep critical copy inside platform-safe margins; export an editable source and final images.

## Presentation

- One decision per slide. Speaker narrative and visible slide copy are separate.
- Animations clarify sequence; they do not decorate every object.
- Provide notes with sources, token values, and asset licenses.

## Video

- Define hook, proof, payoff, CTA, duration, aspect ratio, captions, and safe zones before editing.
- Produce horizontal and vertical edits from the same message architecture, not automatic crop alone.
- Captions are reviewed against audio; licensed audio and image sources are recorded.
- Default execution: model-authored edit decision list and deterministic motion scene -> beat stills -> full render -> FFprobe -> frame QA. A GUI editor is not a prerequisite.

## Interactive promotion

- Disclose odds, eligibility, validity, redemption, privacy handling, and one-use enforcement.
- Define failure/retry states and an accessible non-motion alternative.

## Delivery manifest

Include source files, exports, `brand-package.json`, dimensions/durations, font and asset licenses, QA score, approver, approval date, known limitations, and experiment recommendation.
